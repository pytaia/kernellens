# 07. Метрики

Код: `nullgraft/metrics.py`.

## Локализованная норма $\lVert\cdot\rVert_{p,q,R}$

Основная метрика сравнения в статье (Sec. 5.1.1) задаётся на конечном наборе областей интереса $\mathcal{R}$:

$$
\lVert x\rVert_{p,q,\mathcal{R}} = \Big(\sum_{R \in \mathcal{R}} \lVert x\rVert_{q,R}^{\,p}\Big)^{1/p},
\qquad
\lVert x\rVert_{q,R} = c_R \Big(\sum_{j \in R} |x_j|^q\Big)^{1/q}.
$$

По умолчанию нормировка включена: $c_R = |R|^{-1/q}$. Тогда при одной области:

* $p = q = 1$ — среднее $|x|$ по $R$ (значение по умолчанию в Алгоритмах A и B1);
* $q = 2$ — среднеквадратичное значение по $R$.

`region` принимает одну маску, список масок (набор $\mathcal{R}$) или `None` (всё изображение);
$p, q = \infty$ дают максимум.

**Зачем локализованная.** Деталь площади $a$ пикселей с амплитудой $c$ меняет глобальное среднее $|x|$
изображения из $N$ пикселей лишь на $c\,a/N$. Для узелка 5×5 на срезе 512² это доля 0.01 %: глобальная
норма деталь просто не видит. Локализованная норма на $R$ вокруг детали меняется на величину порядка $c$.

**Свойства.**

* Однородность и неравенство треугольника выполняются, поэтому $d(a,b) = \lVert a - b\rVert_{p,q,R}$ — метрика
  на изображениях с носителем в $\bigcup\mathcal{R}$. Этого достаточно для рассуждений Теоремы 3.2 и
  оценки $\operatorname{diam}/2$ (см. [04](04_algorithm_B1.md)).
* Если области не покрывают всё изображение, это лишь полунорма: изображения, различающиеся вне
  $\bigcup\mathcal{R}$, находятся на расстоянии 0. Результаты о сходимости из Sec. 3.3 статьи тогда не
  применимы. Нижние оценки при этом остаются нижними.

`LocalizedMetric` векторизован по ведущим осям: сравнение батча `(M, L, H, W)` с точкой `(1, 1, H, W)`
делается одним вызовом. Для области «всё изображение» маска не применяется вовсе: по профилю копирование
через булеву маску было узким местом.

## Расстояние Хаусдорфа до точки

$$
d(x, \varphi(y)) = \max_{u \in \varphi(y)} \lVert u - x\rVert_{p,q,R}
$$

(`hausdorff_to_point`). Для стохастических декодеров берётся максимум по семплам: статья определяет ошибку
по худшему элементу множества реконструкций.

## Вспомогательные метрики

| Функция | Формула |
|---|---|
| `rmse(a, b, R)` | $\sqrt{\overline{(a-b)^2}}$ по $R$ |
| `ssim(a, b)` | индекс структурного сходства (`skimage.metrics.structural_similarity`) |
| `to_hu(μ, μ_w)` | $\mathrm{HU} = 1000\,(\mu - \mu_w)/(\mu_w - \mu_{air})$ |
| `hu_error(a, b, μ_w, R)` | средняя абсолютная ошибка в HU по $R$ |
| `dice(a, b)` | $2|a\cap b| / (|a| + |b|)$; для двух пустых масок 1 |

Глобальные метрики (RMSE, SSIM по всему изображению) — вспомогательные: в выводах о галлюцинациях они
не используются.
