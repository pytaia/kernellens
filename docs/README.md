# Документация nullgraft

Пакет реализует методы статьи Iagaru, Gottschling, Hansen, Garnier, *On Hallucinations in Inverse Problems:
Fundamental Limits and Provable Assessment Methods* (arXiv:2605.13146, 2026) для КТ.

Все методы дают **границы возможного, а не диагноз**. Они отвечают на вопрос «могут ли данные подтвердить
эту деталь», а не на вопрос «есть ли там на самом деле опухоль».

| Документ | Что внутри |
|---|---|
| [01_operator.md](01_operator.md) | Модель измерения, преобразование Радона, дискретизация pixel-driven, сопряжённый оператор, бэкенды |
| [02_nullspace.md](02_nullspace.md) | Ядро оператора, проекция $P_N$, LSQR, обусловленность, локальные элементы ядра |
| [03_algorithm_A.md](03_algorithm_A.md) | Алгоритм A: проверка детали для конкретного декодера (Теорема 3.2) |
| [04_algorithm_B1.md](04_algorithm_B1.md) | Алгоритм B1: диаметры допустимых множеств (Алгоритмы 1–2, Теорема 3.9) |

## Обозначения

| Символ | Смысл |
|---|---|
| $x \in \mathbb{R}^{H\times W}$ | изображение (коэффициенты линейного ослабления) |
| $y \in \mathbb{R}^{N_\theta \times n_{det}}$ | синограмма, измерения |
| $A$ | дискретное преобразование Радона, $y = Ax + e$ |
| $e$, $\varepsilon$ | шум измерения, $\lVert e \rVert_2 < \varepsilon$ |
| $\varphi$ | декодер (алгоритм реконструкции), $z \in \varphi(y)$ |
| $\mathcal{N}(A)$ | ядро оператора: $\{x : Ax = 0\}$ |
| $P_N$ | ортогональный проектор на $\mathcal{N}(A)$ |
| $R$ | область интереса (маска пикселей) |
| $\mathcal{F}_y$ | допустимое множество: все реалистичные $x$, объясняющие $y$ с точностью до шума |
| $M_1$ | множество «реалистичных» изображений |

## Как читать

Чтобы просто пользоваться пакетом, достаточно раздела «Суть» в начале документов 03–05.
Формулы и доказательства идут следом. Ограничения каждого метода собраны в конце его документа.
